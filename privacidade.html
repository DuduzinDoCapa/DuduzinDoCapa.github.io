Política de Privacidade do A.I.V.A.D.

Última atualização: novembro de 2026

1. Quem usa

O A.I.V.A.D. é um assistente pessoal de uso privado. Ele é usado apenas pela pessoa que o criou, com a própria conta Google. Não há outros usuários.

2. Quais dados do Google são acessados

  • Google Agenda (escopo calendar.events): ler, criar, alterar e apagar compromissos e lembretes na agenda do próprio usuário, somente quando ele pede.
  • Gmail (escopo gmail.readonly): ler remetente, assunto e data dos e-mails não lidos e, quando o usuário pede, o texto de um e-mail específico, para resumi-lo a ele. O A.I.V.A.D. nunca envia, apaga ou altera e-mails.

3. Como os dados são usados

Os dados do Google são usados exclusivamente para responder aos pedidos do próprio usuário (por exemplo, "o que tenho hoje?" ou "tenho e-mails importantes?"). Para gerar a resposta, o texto necessário é enviado ao serviço de inteligência artificial Gemini, do Google, e não é usado para mais nada.

4. Armazenamento

A autorização de acesso e as informações do assistente ficam guardadas apenas no aparelho do próprio usuário. Não existe servidor externo, banco de dados na nuvem ou cópia em outro lugar.

5. Compartilhamento

Os dados não são vendidos, compartilhados, transferidos a terceiros nem usados para publicidade.

6. Uso limitado

O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

7. Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
